# ระบบแจ้งเตือน

- Navbar นักเรียนและติวเตอร์ใช้ `notification-bell.blade.php` ร่วมกัน จึงมีหน้าตาเหมือนกัน
- นับรายการใน `notifications` ที่เป็นของผู้ใช้ที่ล็อกอิน และมี `is_read` เป็น false
- ระฆังแสดงจำนวนที่ยังไม่อ่าน ถ้าไม่มีจะซ่อนตัวเลข ถ้าเกิน 99 จะแสดง 99+
- จำนวนอัปเดตเมื่อเปิดหน้าใหม่ หรือกดอ่านแล้ว/อ่านทั้งหมด/ลบรายการ
- การนัดหมายใช้แจ้งเตือนคำขอใหม่และผลยืนยัน/ปฏิเสธจากระบบเดิม โดยไม่ได้แก้ appointment/scheduling
- เมื่อส่ง report แจ้งผู้ส่งว่ารับรายงานแล้ว และแจ้งแอดมินที่ใช้งานอยู่ให้ตรวจสอบ
- เมื่อแอดมินเปลี่ยนสถานะ แจ้งผู้ส่งรายงาน ถ้าบันทึกสถานะเดิมจะไม่ส่งซ้ำ
- ไม่แจ้งติวเตอร์ที่ถูกรายงาน และไม่ใส่รายละเอียดปัญหาในข้อความแจ้งเตือน

ใช้ตาราง `notifications` และ `notification_types` เดิม โดยเพิ่มข้อมูลประเภท `REPORT0001` เฉพาะเมื่อระบบส่งแจ้งเตือนรายงานครั้งแรก ตามที่ผู้ใช้อนุญาต ไม่เพิ่มตาราง คอลัมน์ หรือรัน Seeder ในฐานข้อมูลจริง

`ReportNotification::send()` เป็นฟังก์ชันสั้น ๆ ที่ใช้ร่วมกันสองจุด เพื่อไม่ต้องเขียนการสร้างแจ้งเตือนซ้ำ ส่วน `DB::transaction()` ใช้ให้รายงาน/สถานะและแจ้งเตือนบันทึกสำเร็จพร้อมกัน
