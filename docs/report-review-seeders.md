# Seeder รายงานและรีวิว

ข้อมูลใช้ตารางและความสัมพันธ์จริงของระบบ ไม่เพิ่มตาราง/คอลัมน์ ไม่แก้ UI และไม่แก้โค้ด schedule/availability

## บัญชีนักเรียน

`StudentSeeder` เพิ่มพิม เรียนดี: `pim@example.com` รหัสผ่านเริ่มต้น `password` พร้อม StudentProfile ใช้เชื่อมข้อมูลรายงานและรีวิว

## รายงาน

`ReportSeeder` เพิ่ม 3 รายการสำหรับบัญชีพิม โดยอ้างติวเตอร์เนเน่/แพรวและ ReportReason เดิม:

| รหัส | ติวเตอร์ | สถานะ |
| --- | --- | --- |
| SEEDRPT001 | เนเน่ | pending — รอตรวจ |
| SEEDRPT002 | แพรว | in_progress — กำลังตรวจ |
| SEEDRPT003 | เนเน่ | resolved — ตรวจเสร็จ |

รายงานแสดงในหน้าแอดมินจริง และสร้างแจ้งเตือนถึงผู้ส่งกับแอดมินที่เปิดใช้งาน การรันซ้ำไม่สร้างรายงาน/แจ้งเตือนซ้ำ และไม่ทับสถานะหรือข้อความที่แอดมินแก้ไปแล้ว

```sh
php artisan db:seed --class=ReportSeeder
```

## รีวิว

`CompletedLessonSeeder` เพิ่มนัดหมายย้อนหลัง 4 รายการที่ผู้ใช้อนุญาต รหัส SEEDAPP001–SEEDAPP004 ของพิมกับเนเน่/แพรว คนละ 2 คาบ คาบละ 1 ชั่วโมง สถานะ completed โดยไม่แก้นัดหมายเดิม ไม่เพิ่มหรือแก้ availability และไม่แก้โค้ด schedule

`ReviewSeeder` ใช้เฉพาะนัดหมาย 4 รายการนี้ของพิมกับเนเน่/แพรวที่มีสถานะ completed และสิ้นสุดในอดีต สร้างรีวิวเชื่อม Appointment และ TutorProfile จริง แล้วคำนวณคะแนนเฉลี่ยจากรีวิวที่ไม่ถูกซ่อน ไม่สร้างข้อความรีวิวอัตโนมัติให้การเรียนจริงครั้งใหม่ในอนาคต

หนึ่งนัดหมายมีหนึ่งรีวิว ตรวจรายการที่ soft delete ด้วย ไม่คืนรีวิวที่แอดมินซ่อน และไม่เปลี่ยนข้อความ/คะแนนของรีวิวที่มีอยู่

```sh
php artisan db:seed --class=CompletedLessonSeeder
php artisan db:seed --class=ReviewSeeder
```

หากไม่มีนัดหมายที่เรียนจบ Seeder จะแจ้งว่าข้ามการเพิ่มรีวิว โดยไม่แก้สถานะนัดหมายเดิมหรือสร้างนัดหมายขึ้นเอง

Seeder ทั้งหมดถูกเพิ่มใน DatabaseSeeder แล้ว เพื่อเรียกด้วย `php artisan db:seed` ตามปกติ โดย TutorSeeder ทำงานก่อน ReportSeeder และ CompletedLessonSeeder ทำงานก่อน ReviewSeeder
