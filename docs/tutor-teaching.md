# วิชาของฉันและการยืนยันคำขอเรียน

## วิธีใช้งาน

1. เข้าสู่ระบบเป็นติวเตอร์ แล้วกดเมนู **วิชาของฉัน** (`/tutor/subjects`)
2. เลือกวิชาจากรายการของแอดมิน ตั้งรูปแบบการสอน และกรอก Line/Discord/Zoom/Google Meet แล้วบันทึก
3. เปิดเมนู **จัดเวลา** (`/tutor/schedule`) เพื่อเพิ่มหรือนำเวลาว่างออก ช่วงเวลาต้องอยู่ในอนาคตและไม่ทับเวลาว่างเดิม
4. นักเรียนเปิดโปรไฟล์ติวเตอร์ เลือกวิชา วันและเวลาที่เปิดไว้ แล้วส่งคำขอ
5. ติวเตอร์เปิด **ตารางนัดหมาย** เลือกคำขอรอยืนยัน แล้วกดยืนยันหรือปฏิเสธ
6. นัดที่ยืนยันแล้วแสดงในหน้าหลักนักเรียนและตารางนัดหมาย นักเรียนกดรายละเอียดเพื่อดูช่องทางเรียนได้

## ข้อมูลที่ใช้

ไม่มีตารางหรือคอลัมน์ใหม่ ตามที่ผู้ใช้เลือก รูปแบบการเรียนและช่องทางเรียนใช้ข้อมูลปัจจุบันของโปรไฟล์ติวเตอร์ ไม่บันทึกข้อมูลแยกในแต่ละนัดหมาย ถ้าติวเตอร์เปลี่ยนข้อมูล นักเรียนจะเห็นข้อมูลล่าสุด

- `subjects`: รายวิชากลาง แอดมินเป็นผู้จัดการ
- `tutor_profiles_has_subjects`: วิชาที่ติวเตอร์เลือกเปิดสอน การนำวิชาออกไม่ลบนัดหมายเดิม
- `tutor_profiles.teaching_mode`: ออนไลน์ นัดเจอ หรือทั้งสองแบบ
- `contacts`: ช่องทางเรียนของผู้ใช้เจ้าของโปรไฟล์
- `availabilities`: ใช้ user_id และวันเวลาเริ่ม/สิ้นสุดเดิม
- `appointments`: สถานะ วันเวลา subject_id tutor_id และ student_profiles.id เดิม
- `notifications` / `notification_types`: คำขอใหม่และผลการตอบรับ ส่งให้ user_id จริง

การนำเวลาว่างออกจะปิดเฉพาะช่วงรับคำขอใหม่ ไม่ยกเลิกนัดหมายเดิม ส่วนการเปลี่ยนวันของนัดเดิมให้คู่ผู้เรียน/ติวเตอร์ตกลงกันก่อน

## โค้ดสำหรับอธิบายตอนพรีเซนต์

- `TutorTeachingController.php`: ดึงข้อมูลของติวเตอร์ที่ล็อกอิน ตรวจฟอร์ม แล้วบันทึกวิชาและช่องทาง หรือเพิ่ม/ลบเวลาว่าง
- `AppointmentController.php`: นักเรียนส่งคำขอจากบัญชีตัวเอง ติวเตอร์ตรวจได้เฉพาะคำขอของตน และส่งแจ้งเตือนให้ผู้เรียนจริง
- `StudentHomeController.php`: ดึงนัดที่ confirmed และยังไม่สิ้นสุดของนักเรียนที่ล็อกอินมาแสดง
- `NotificationController.php`: อ่านและจัดการการแจ้งเตือนของผู้ใช้ปัจจุบัน

ใช้ if, foreach, Blade และ Eloquent ตามรูปแบบเดิม `DB::transaction()` ทำให้สถานะกับการแจ้งเตือนบันทึกสำเร็จพร้อมกัน `lockForUpdate()` ใช้กันคำขอพร้อมกันขณะตรวจเวลาทับซ้อน ไม่ได้สร้างระบบอนุมัติบทบาทติวเตอร์เพิ่ม

## การตรวจสอบ

```bash
php artisan test --compact tests/Feature/TutorTeachingTest.php
```

ทดสอบเมนู active การแก้เฉพาะข้อมูลตนเอง เวลาว่างทับซ้อน ความถูกต้องของผู้เรียน/ผู้รับแจ้งเตือน การยืนยัน การปฏิเสธ ช่องทางหลังยืนยัน และการป้องกันคนอื่นเข้าถึงนัดหมาย
